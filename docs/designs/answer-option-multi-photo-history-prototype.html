Multi-Photo History View — Mobile Prototype

Mockup for viewing all submitted photos on past rounding interactions. Navigate via Activity Feed (patient census) or History (patient profile). Tap any thumbnail to preview full size.

Navigation paths

  • Path A — Activity FeedPatient census → tap Activity Feed icon on card → Patient Rounds list → View Details
  • Path B — History tabPatient profile → History tab → Patient Rounds list → View Details

Both paths land on the same Patient Rounds Details screen where photos appear under each answered question.

Design notes

Grid layout: 3 columns, square thumbnails with 6px gap. Scales from 1–10 photos — partial last row for 4, 7, or 10 photos.

Backend needs: Return orchid_image_urls[] on completed interaction answers (not just a single URL).

Tap behavior: Opens full-screen viewer with swipe/arrows to browse all photos for that answer.

List preview (optional): First card shows a horizontal strip of up to 4 thumbnails + "+N" overflow on the history list — helps users spot photo-documented rounds at a glance.
